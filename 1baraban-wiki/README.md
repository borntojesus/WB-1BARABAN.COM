# 1baraban Wiki

Knowledge base & Map of Content (MOC) for the **1baraban.com** iGaming review platform.

## Project Snapshot

- **Brand**: 1baraban (final)
- **Geo**: EU + Global English (English as primary)
- **Verticals**: Casino · Sports Betting · Poker · Slots
- **Monetization**: Affiliate (RevShare / CPA / Hybrid)
- **Stack**: Strapi v5 (CMS) · Nuxt 3 + Vue 3 (frontend, SSR/SSG) · Vercel (Fluid Compute) · Vercel AI SDK + AI Gateway · Postgres (Neon)
- **Differentiators**: AI Chat concierge · Deep SEO/GEO · LLM-citation-first content
