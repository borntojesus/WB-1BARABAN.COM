Scope: audit only. No code, deploy, or noindex changes. Method: curl against live prod, repo and git checks, GSC via MCP, PSI.

The site is up and healthy on Netlify (HTTP 200, 18 of 18 sitemap URLs return 200, no broken internal links in a 36-link sample). Prod matches the latest pushed commit. The main gaps are measurement (no GSC access, PSI and Ahrefs unavailable), a sitemap that is much smaller than DEPLOY.md's 49 routes, and a noindex page that conflicts with the fleet rule.

## Findings, ranked

### Medium
1. **GSC not accessible.** The `mail` MCP service account has no permission on `sc-domain:1baraban.com` or `https://1baraban.com/` (tried channels borntojesus, dmitry, engineering). No search data was available. Fix: add the service account as a user on the GSC property, or verify the domain property under an account the MCP can reach.
2. **`/ask` is `noindex, nofollow`** (200, not in sitemap). The fleet rule forbids noindex without Dmytro's Telegram approval via Odin, and your brief treats any noindex as a bug. DEPLOY.md documents it as intentional ("only /ask is noindex"). Decision needed: approve it as a system page, or remove it.
3. **Sitemap has 18 page URLs, DEPLOY.md expects 49 prerendered routes.** The difference is likely excluded or utility pages, but it is unconfirmed. Missing from the sitemap and worth checking: any hub, blog, or extra author or review pages. Only 5 reviews (bcgame, bitstarz, leovegas, mr-green, stake) and 2 authors are indexed.
4. **Thin site for the topic.** 5 operator reviews on a gambling affiliate site is very little to rank for "best online casinos" style queries. Ranking potential is limited by content volume, not by technical SEO.

### Low
5. **No hreflang** on any page; only `lang="en"`. Fine for a single-language site. Add only if localisation is planned (copy says "EU and global").
6. **Titles contain an HTML-escaped slash**, `8.7&#x2F;10`. Browsers and Google decode it, so this is cosmetic, but it signals over-escaping in the title template.
7. **Titles over typical length** on some pages (for example the home title and review meta descriptions run past ~155 characters and will be truncated in snippets). Review meta descriptions are cut mid-sentence in the data I pulled.
8. **Em dashes in client-facing copy** (home and about meta descriptions use "—"), against the copy rule for sites that readers see.
9. **robots.txt `Disallow: /go/` and `/search`**: fine and intended (affiliate redirects). `/go/stake` returns 404 on the live site, so the affiliate redirect path is not active or the slug differs. Verify the `_redirects` file was deployed; if `/go/` links are expected to earn, they currently do not resolve.
10. **robots.txt is fine for AI bots**: default `User-agent: *` allows everything; no bot is blocked. The explicit Allow groups for PerplexityBot, ChatGPT-User, ClaudeBot, GoogleOther are harmless. GPTBot, Google-Extended and others fall under `*`, which is also Allow.
11. **No `/llms.txt`** (404). Optional.

### Passed
- No `noindex` on any of the 6 key pages checked (home, about, compare, online-casinos, reviews/stake, slots, methodology); all carry `index, follow, max-image-preview:large`.
- Unique title, description and self-referencing canonical on every sampled page, one `<h1>` each.
- Schema: WebSite, Organization, WebPage, ItemList on hub pages; `Review` and `Person` on review pages; `ImageObject` on about, compare, methodology.
- Real 404 for unknown paths (HTTP 404). `/favicon.ico` 200.
- Third-party scripts: only Google Tag Manager `GTM-KW7J287K`, with Consent Mode default `denied` for EU regions and a consent banner (`/scripts/consent.js`). No unexpected or injected scripts found in the home HTML.
- Speed (server side): TTFB and full download for the HTML 0.45 to 0.66 s for 55 to 97 KB pages.
